# Spec: Profile site at dev/resume

**id:** T1.1  **intent:** .buildloop/intent/T1.1.md
**policies applied:** acker-design, ~/dev/CLAUDE.md, ~/.claude/CLAUDE.md
**status:** accepted (reconstructed, see intent)

## Summary
A single static page rendering Zac's professional history from a typed data
module, styled with the acker.cloud tokens, dark only.

## Requirements
R1. Content transcribed from the live LinkedIn profile, his wording preserved.
R2. All content in one data module; the page reads it and does not restate it.
R3. acker.cloud tokens only. No second palette, no blue carrying meaning.
R4. Static prerender. No client data fetching.
R5. Prints to legible ink on paper.

## Design
- `lib/profile.ts` holds profile, experience, education, skills as typed data.
- `app/page.tsx` renders sections in a two column timeline: dates left, content
  right, collapsing to one column under `sm`.
- `app/globals.css` registers acker tokens in Tailwind's `@theme`.
- `scripts/contrast.mjs` measures every colour pair and gates the build.

## Acceptance criteria
AC1. `pnpm build` exits 0                          | `pnpm build`
AC2. `tsc --noEmit` reports no errors              | `pnpm typecheck`
AC3. Every enforced colour pair clears WCAG AA     | `pnpm check:contrast`
AC4. Zero em-dashes in authored copy               | `grep -rn '—' app lib scripts`
AC5. Route `/` prerenders as static                | build output shows a static route

## Ordering surface
none. A static prerendered page. No concurrency, no shared mutable state, no
persistence, no messaging, no partial failure. Formal verification does not
apply and VERIFY records the skip with this reason.

## Policy conflicts
Two, both raised against the acker-design reference rather than decided
silently. See the verify report: `--accent` fails as text at 3.20:1, and the
reference's primary button pairing fails at 3.39:1.

## Rejected alternatives
- Static HTML with no build step, matching the `personal` project. Rejected:
  the global stack rule names Next.js for frontend work.
- Cloning LinkedIn's visual design. Rejected: trade dress, and it is the wrong
  thing to ship on his own domain.
